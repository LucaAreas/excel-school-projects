# Excel School Projects

Arquivo de exercícios de Excel feitos durante o curso técnico de informática.

## Sobre o projeto

Coleção de planilhas praticando funcionalidades do Excel trabalhadas em aula,
incluindo fórmulas de busca (PROCV), estruturas de pedido/estoque e um
exercício com dados de hospital.

## Conteúdo

- `AULA 01` — exercícios introdutórios
- `AULA 02` e `AULA 03` — prática com dados de hospital
- `AULA 04` — PROCV (VLOOKUP) e estrutura de pedido
- `AULA 05` — exercício de fixação

## Observação

Este repositório é um arquivo de aprendizado, não um projeto único e
polido — reúne exercícios de diferentes aulas do curso técnico.
